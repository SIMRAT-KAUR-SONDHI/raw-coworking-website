# RAW Coworking Website

This is a clean, responsive, and modern static website for **RAW Coworking**. The website is built using original **HTML, CSS, and JavaScript** and is suitable for deployment on **GitHub Pages**.

The website represents a coworking space business and includes sections such as home, services, locations, amenities, FAQs, and contact details.

## Project Overview

The main purpose of this project is to create a simple and professional business website for RAW Coworking. It is designed to provide users with important information about coworking spaces, private cabins, meeting rooms, virtual offices, and available facilities.

The website is fully static, which means it does not require any backend server or database. It can be hosted easily using GitHub Pages.

## Features

* Responsive design for desktop, tablet, and mobile screens
* Modern landing page layout
* Smooth navigation between sections
* Services section for coworking solutions
* Amenities and features section
* Location and contact information
* FAQ section for common user queries
* Contact form using `mailto:`
* Clean and organized code structure

## Technologies Used

* HTML5

## File Description

### `index.html`

This file contains the main structure of the website. It includes all the sections such as navbar, hero section, services, amenities, FAQ, and contact section.

### `styles.css`

This file contains the styling of the website. It controls the layout, colors, fonts, spacing, responsiveness, buttons, cards, and overall design.

### `script.js`

This file contains JavaScript code used for interactive features such as mobile menu, FAQ toggle, smooth scrolling, and other small website interactions.

### `logo.svg`

This file contains the website logo used in the header or branding section.

### `README.md`

This file contains project details, setup instructions, file structure, and deployment information.

## How to Run This Project Locally

You can run this project directly by opening the `index.html` file in your browser.

Steps:

1. Download or clone the repository.
2. Open the project folder.
3. Double-click on `index.html`.
4. The website will open in your browser.

You can also run it using a local server:

```bash
python -m http.server 8000
```

Then open this link in your browser:

```text
http://localhost:8000
```

## Deployment on GitHub Pages

Follow these steps to deploy the website on GitHub Pages:

1. Open your GitHub repository.
2. Go to **Settings**.
3. Click on **Pages** from the left sidebar.
4. Under **Build and deployment**, select:

   * Source: `Deploy from a branch`
   * Branch: `main`
   * Folder: `/root`
5. Click on **Save**.
6. Wait for a few minutes.
7. GitHub will generate a live website link.

## Contact Form Note

This is a static website, so the contact form does not store data in a database. The form uses `mailto:`, which opens the user's email application to send a message.

For a fully working backend contact form, services like Formspree, Netlify Forms, Google Forms, or a custom backend API can be used.
